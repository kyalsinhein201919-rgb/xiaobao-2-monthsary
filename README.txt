# 2 Monthsary Surprise — ကျဝ်ကျဝ် × 小宝

## Vercel တင်နည်း
1. ဒီ folder ကို GitHub repository အသစ်ထဲ upload လုပ်ပါ။
2. vercel.com ကိုဝင်ပြီး **Add New → Project** ကိုရွေးပါ။
3. GitHub repository ကို Import လုပ်ပါ။
4. Framework Preset ကို **Other** (သို့) default ထားပြီး Deploy လုပ်ပါ။
5. Deploy ပြီးရင် ရလာတဲ့ `vercel.app` link ကို 小宝 ဆီပို့လိုက်ပါ ❤️

`assets/` folder ထဲက ပုံ/ဗီဒီယိုတွေကို မဖျက်ပါနဲ့။
